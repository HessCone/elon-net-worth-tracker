    Data & method

    Source

    The number comes from Forbes Real-Time Billionaires. A script reads the public JSON Forbes's own page uses (raw JSON). No paid API key. If that file fails, the script tries Forbes's real-time list, then the list feed, and the page names which one was used. This reading: —.

    Holdings

    Tesla and SpaceX are the positions Forbes prices. Stock is shares times price. Options are shares times (price minus strike), which is what makes those lines add up to Forbes's total. Other private assets are Forbes's unpublished split. Forbes's profile says SpaceX acquired xAI, so xAI is not a separate line, and it mentions stakes in The Boring Company and Neuralink without dollar amounts.

    History & time

    The chart starts from Forbes's own wealth history (about a month of daily readings and a week of hourly ones), labeled as rounded. After that, GitHub Actions saves a new reading at least once an hour. Today, 7 days, and 30 days only appear when an earlier point actually covers that window. Times are US Central.
